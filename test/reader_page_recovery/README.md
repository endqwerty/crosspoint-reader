The host target extracts the contiguous production page-load/render/progress block, resume-selection block, deferred-position methods, chapterPosition(), and footnote-exit save method from EpubReaderActivity.cpp. Only storage, painting, and persistence endpoints are stubbed. Tests cover later-page failure, retry exhaustion, stale offsets, resolved search/anchor destinations, nested notes and ordinary links, and incremental-build recovery. They do not model SD electrical faults or physical display timing.
